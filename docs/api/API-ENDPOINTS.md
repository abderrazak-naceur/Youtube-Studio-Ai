# API Endpoints

## Workspaces

`GET /workspaces`
`POST /workspaces`
`GET /workspaces/{id}`

## Channels

`GET /channels`
`POST /channels`
`GET /channels/{id}`
`PATCH /channels/{id}`

## Opportunities

`GET /opportunities`
`POST /opportunities/research`
`POST /opportunities/{id}/select`

## Content

`POST /content/projects`
`POST /content/{id}/research`
`POST /content/{id}/script`
`POST /content/{id}/scenes`

## Production

`POST /production/{id}/generate`
`GET /jobs/{id}`
`POST /jobs/{id}/cancel`

## Publishing

`POST /publications`
`POST /publications/{id}/approve`
`POST /publications/{id}/publish`

## Analytics

`GET /analytics/videos/{id}`
`GET /analytics/channels/{id}`
`GET /analytics/portfolio`
