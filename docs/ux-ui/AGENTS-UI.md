# AI Agents UI

## Agent center

Show:

- agent status
- current task
- queue
- estimated cost
- tools used
- outputs
- failures
- approvals required

## Autonomy control

Levels:

0 Manual
1 Copilot
2 Approval required
3 Bounded autonomy
4 Strategic autonomy

Sensitive actions such as publishing, deleting assets, spending above budget or changing credentials require explicit permissions.

## Trace view

Users can inspect a concise execution trace: goal → plan → tools → results → decision → output.
