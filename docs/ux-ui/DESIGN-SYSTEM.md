# Design System

## Direction

Professional AI-native SaaS: calm, dense where useful, highly legible and data-oriented.

## Tokens

Define semantic tokens for:

- background
- surface
- elevated surface
- text primary/secondary
- border
- success/warning/error/info
- brand accent
- interactive states

Do not hard-code provider/model colors into product logic.

## Components

- AppShell
- Sidebar
- Topbar
- Breadcrumbs
- Command palette
- DataTable
- MetricCard
- OpportunityCard
- AgentStatus
- JobProgress
- EvidenceCard
- AssetCard
- VideoTimeline
- CostBreakdown
- ApprovalDialog
- EmptyState
- ErrorState
- Toast

## Accessibility

Target WCAG 2.2 AA where applicable. Keyboard navigation, visible focus, semantic labels, reduced-motion support and sufficient contrast are required.
