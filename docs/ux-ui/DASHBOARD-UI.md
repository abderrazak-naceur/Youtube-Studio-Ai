# Dashboard UI

## Goal

Give the user a single view of what matters today.

## Sections

### Business health
- revenue
- production cost
- contribution margin
- active channels

### Content pipeline
- opportunities
- research
- scripting
- production
- QA
- scheduled

### AI activity
- jobs running
- failed jobs
- provider spend
- estimated remaining budget

### Recommendations
Cards such as:

- `3 opportunities are above your current threshold`
- `Video X is underperforming mainly because of packaging`
- `Production spend is 18% above plan`

## UI behavior

Dashboard cards must link directly to the object/action that resolves the issue. Avoid decorative metrics without a decision attached.
