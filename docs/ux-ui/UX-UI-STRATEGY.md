# UX/UI Strategy

## Product philosophy

YouTube Studio AI must feel like a professional operating system, not a collection of AI chat boxes.

The interface should expose the business loop:

`Discover → Decide → Research → Create → Produce → QA → Publish → Measure → Monetize`

## UX principles

1. Outcome-first, not model-first.
2. Show why the AI made a recommendation.
3. Make cost visible before expensive generation.
4. Keep users in control of publication and sensitive actions.
5. Progressive disclosure for advanced settings.
6. Every AI action has status, provenance and retry behavior.
7. The same object should have one canonical home.

## Navigation

- Dashboard
- Opportunities
- Research
- Content
- Production
- Calendar
- Channels
- Analytics
- Revenue
- AI Agents
- Assets
- Settings

## Primary CTA

The main action should change by context: `Find Opportunity`, `Create Video`, `Continue Production`, `Review`, or `Publish`.
