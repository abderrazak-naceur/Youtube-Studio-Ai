# Channel DNA UI

## Sections

- mission
- audience
- positioning
- tone
- vocabulary
- visual identity
- recurring formats
- topics to avoid
- monetization priorities
- quality bar

## AI behavior

Every content recommendation should be explainable against Channel DNA.

Example:

`Recommended because: audience fit 92%, topic fit 88%, monetization fit 76%, historical format similarity 81%.`

## Editing

Allow the user to edit rules in plain language while the system maintains a structured machine-readable representation.
