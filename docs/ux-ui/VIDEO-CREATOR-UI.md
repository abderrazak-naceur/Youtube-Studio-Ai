# Video Creator UI

## Layout

```text
┌────────────────────────────────────────────────────────────┐
│ Project / Channel                         Cost / Status    │
├───────────────┬───────────────────────────┬────────────────┤
│ Script        │ Scene / Preview           │ AI Assistant   │
│ Outline       │ Timeline                  │ Suggestions    │
│ Claims        │                           │ Warnings       │
├───────────────┴───────────────────────────┴────────────────┤
│ Assets │ Voice │ Captions │ Music │ Thumbnail │ Metadata   │
└────────────────────────────────────────────────────────────┘
```

## Workflow

1. Brief
2. Script
3. Scene plan
4. Generate assets
5. Voice
6. Timeline
7. Captions
8. Thumbnail/metadata
9. QA
10. Export

## Cost visibility

Before expensive generation, show estimated credits/cost. After generation, show actual cost and provider/model used.
