# Opportunity Engine UI

## Opportunity card

Each opportunity displays:

- title
- audience/problem
- demand signal
- competition
- monetization potential
- freshness
- estimated production cost
- Opportunity Score
- Revenue Score
- confidence

## Actions

- Research
- Add to backlog
- Generate brief
- Compare
- Ignore

## Explainability

A `Why this score?` drawer shows evidence and scoring factors. The user can change thresholds without editing model prompts.

## Portfolio view

Allow sorting by expected business value, not only views or popularity.
