# Information Architecture

```text
Workspace
├── Dashboard
├── Channels
│   ├── Channel overview
│   ├── Channel DNA
│   └── Content calendar
├── Opportunities
├── Research
├── Content
│   ├── Ideas
│   ├── Scripts
│   └── Scene plans
├── Production
│   ├── Projects
│   ├── Assets
│   └── Renders
├── Publishing
├── Analytics
├── Revenue
├── Agents
└── Settings
```

## Object hierarchy

Workspace → Channel → Content Project → Video → Scenes → Assets → Render → Publication → Analytics → Revenue.

The UI must preserve this hierarchy in breadcrumbs and contextual navigation.
