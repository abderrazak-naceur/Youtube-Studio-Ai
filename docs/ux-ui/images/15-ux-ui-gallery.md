# UI/UX Visual Gallery

These editable SVG mockups are the visual reference set for the YouTube Studio AI product.

## Screens

1. [Dashboard](./01-dashboard.svg) — business health, KPIs, growth and recent videos.
2. [Opportunities](./02-opportunities.svg) — demand, competition, monetization and opportunity score.
3. [Research](./03-research.svg) — evidence, sources, claims and research workflow.
4. [Video Creator](./04-video-creator.svg) — idea, script, visual style and generation flow.
5. [Production](./05-production.svg) — asset generation, rendering and QA progress.
6. [Publishing](./06-publishing.svg) — metadata, publication gate and YouTube publishing.
7. [Analytics](./07-analytics.svg) — performance diagnosis and recommended experiments.
8. [Revenue](./08-revenue.svg) — revenue streams, growth and AI CFO recommendations.
9. [AI Agents](./09-agents.svg) — agent status, budgets, confidence and audit trace.
10. [Channels](./10-channels.svg) — multi-channel portfolio management.
11. [Settings](./11-settings.svg) — provider and workspace configuration.
12. [Onboarding](./12-onboarding.svg) — workspace setup and YouTube connection.
13. [Mobile](./13-mobile.svg) — responsive companion experience.
14. [Design System](./14-design-system.svg) — tokens, components and interaction principles.

## Usage

Use these screens as the visual source of truth while implementing the frontend. Keep the information architecture and workflow states aligned with the UX/UI documentation in the parent directory.
