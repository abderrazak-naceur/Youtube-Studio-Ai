# AI Evaluation

## Dimensions

- factuality
- relevance
- originality
- narrative quality
- visual consistency
- instruction adherence
- safety
- cost efficiency
- latency

## Evaluation set

Maintain versioned datasets for each major agent. Include normal, adversarial, edge and multilingual cases.

## Release rule

A new model/provider may enter production only if it meets minimum quality thresholds and improves or preserves unit economics.

## Human evaluation

Use blinded human review for subjective dimensions and calibrate automated evaluators against human judgments.
