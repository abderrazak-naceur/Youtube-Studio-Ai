# E2E Tests

## Critical journeys

1. Create workspace.
2. Connect channel.
3. Select opportunity.
4. Research and fact-check.
5. Generate script.
6. Generate media through provider adapter.
7. Render video.
8. Run QA.
9. Approve publication.
10. Publish.
11. Ingest analytics.
12. Calculate cost/revenue.

## Provider failure scenarios

Test timeout, rate limit, invalid credentials, partial output, duplicate callback and provider outage. The user should see an actionable status rather than a generic error.
