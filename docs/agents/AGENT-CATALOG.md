# Agent Catalog

## Opportunity Agent
Finds and ranks content opportunities.

## Research Agent
Collects evidence and creates structured research.

## Fact Checker
Validates claims and flags uncertainty.

## Script Agent
Transforms approved research into original narrative.

## Producer Agent
Converts scenes into asset and rendering jobs.

## QA Agent
Checks technical, editorial, rights and policy requirements.

## Analytics Agent
Explains performance and recommends experiments.

## AI CFO
Optimizes budget and monetization.

## AI CEO
Coordinates business-level priorities under explicit permissions.

All agents share a common contract: goal, inputs, tools, budget, output schema, confidence, provenance, risks and audit trace.
