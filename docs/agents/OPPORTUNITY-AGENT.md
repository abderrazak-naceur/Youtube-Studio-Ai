# Opportunity Agent

## Goal
Identify topics with the highest expected business value for a channel.

## Inputs
- Channel DNA
- historical performance
- market signals
- audience problems
- monetization context
- production cost model

## Output
Opportunity with score, rationale, evidence, confidence, risks and suggested format.

## Guardrails
Never treat popularity alone as business value. Avoid fabricated demand signals. Preserve evidence provenance.
