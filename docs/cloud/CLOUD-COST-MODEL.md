# Cloud Cost Model

## Reference scenarios

These are planning envelopes, not provider quotations.

| Stage | Infrastructure target/month |
|---|---:|
| Prototype | €50–€300 |
| MVP | €200–€1,500 |
| Early SaaS | €1,000–€5,000 |
| Growth | €5,000–€25,000 |
| Scale | €25,000+ |

AI generation can dominate these figures and must be modeled separately.

## Required dashboard

Track monthly:

- compute
- database
- object storage
- egress/CDN
- queue/cache
- monitoring
- backups
- AI provider spend
- cost per active user
- cost per generated minute
- cost per published video

## Rule

No provider price is treated as permanent. Before every annual budget cycle, refresh official pricing and recalculate unit economics.
