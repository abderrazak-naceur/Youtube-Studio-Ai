# Break-Even Analysis

## SaaS

`BreakEvenCustomers = FixedMonthlyCosts / (ARPA × GrossMargin)`

Example planning scenario:

- fixed costs: €25,000/month
- ARPA: €100/month
- gross margin: 70%

Break-even ≈ `25,000 / 70 = 358 customers`.

This is an illustrative example only.

## Owned media

`BreakEvenVideos = FixedMediaCosts / ContributionPerVideo`

Because video revenue is delayed and variable, the company should track cohort payback rather than expecting every video to be profitable immediately.

## Company break-even

Combine SaaS gross profit + media contribution + services + other recurring revenue and subtract fixed operating costs.
