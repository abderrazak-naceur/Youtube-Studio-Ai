# Content Engine

## Objective

Turn validated opportunities into original, evidence-based content that matches Channel DNA and is designed for audience value and business value.

## Pipeline

```text
Opportunity
→ Research
→ Claims
→ Fact Check
→ Narrative
→ Script
→ Scene Plan
→ Metadata
→ QA
```

## Opportunity Score

The initial score can combine:

- audience demand
- search intent
- trend momentum
- competition
- channel fit
- monetization potential
- production effort
- originality potential
- evidence quality

Weights must remain configurable because different channels have different economics.

## Research

Research should produce:
- source list
- source reliability
- claims
- evidence excerpts/references
- unresolved questions
- publication date
- freshness requirement

The Research Agent must distinguish facts, estimates, opinions and assumptions.

## Fact checking

Each material claim receives a state:

`verified | partially_verified | disputed | unsupported | outdated`

Unsupported material claims should block publication until resolved or removed.

## Script architecture

A script should normally contain:
- hook
- promise/context
- main narrative
- evidence/examples
- transitions
- conclusion
- CTA when strategically justified

The system should optimize for clarity, retention and usefulness without generating deceptive clickbait.

## Channel DNA

Channel DNA controls:
- audience
- positioning
- tone
- vocabulary
- pacing
- visual style
- recurring formats
- editorial rules
- forbidden patterns
- monetization strategy

## Content Genome

Every completed video should be decomposed into reusable learning attributes:
- topic
- subtopic
- hook type
- format
- length
- emotional angle
- information density
- CTA type
- thumbnail concept
- title pattern
- audience segment
- performance outcomes

The Genome is a learning dataset, not a copy-generation mechanism.

## Originality policy

The system should add meaningful original value: analysis, synthesis, explanation, examples, commentary, demonstrations or other creative contribution. Avoid repetitive template content whose substance is substantially unchanged from video to video.
