# v0.8 Music/SFX

## Scope
Advance the MVP production loop from Voice to Music/SFX. The API exposes music/SFX generation through the replaceable `IMusicSfxProvider` boundary and persists the resulting production artifact.

## Endpoint

`POST /api/v1/video-projects/{id}/music-sfx`

The endpoint requires the project to be in `Producing` state, a non-empty persisted Script artifact, and a valid persisted ScenePlan. The target audio duration is derived by summing the scene durations from the latest scene plan. The provider receives the project title, script, and derived duration.

Provider credentials remain outside the API contract and are never persisted or hard-coded. A successful provider response must contain a provider asset id and media type before a `MusicSfx` artifact is persisted.

## Persistence

The endpoint stores the provider asset id as `ProductionArtifact.ProviderAssetId` and media type plus the target duration in `MetadataJson`. The project remains in `Producing` so subsequent production stages can consume the accumulated assets.

## Verification

Backend regression coverage includes missing projects, invalid state, missing script, invalid scene plan, provider request propagation, successful artifact persistence, and invalid provider output without partial persistence.
