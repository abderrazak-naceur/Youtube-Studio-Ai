# v0.25 Channel DNA (Versioned)

## Purpose

Versioned editorial identity per channel (backlog US-005, DATA-MODEL Channel DNA + §3 versioning).

## Model

`ChannelDna` (table `channel_dna`, migration `20260929211100_AddChannelDna`): `ChannelId`, `Version` (1-based), plus `Audience`, `Positioning`, `Tone`, `VisualLanguage`, `RecurringFormats`, `ForbiddenPatterns`, `StrategicGoals`. Unique index on `(ChannelId, Version)`.

## API (workspace-scoped via the channel)

- `POST /api/v1/channels/{channelId}/dna` — saves a new DNA version (`max + 1`); never overwrites a prior version.
- `GET /api/v1/channels/{channelId}/dna` — latest version (`404` if none).
- `GET /api/v1/channels/{channelId}/dna/versions` — full version history, newest first.

Non-members get `404`.

## Verification

Backend coverage: creating DNA appends versions (1, 2, …); latest returns the highest version; 404 when no DNA; non-member blocked. New migration and `channel_dna` table verified in CI.
