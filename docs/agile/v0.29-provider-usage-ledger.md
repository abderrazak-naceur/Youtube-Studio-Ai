# v0.29 Provider Usage Ledger

## Purpose

Record every external provider call and its cost at call granularity (AI-COST-MODEL cost ledger, README usage/cost tracking, PROVIDER-INTEGRATIONS cost/usage metadata).

## Model

`ProviderUsage` (table `provider_usage`, migration `20260929212816_AddProviderUsage`), append-only, with the ledger fields required by AI-COST-MODEL: `Provider`, `Model`, `TaskType`, `InputUnits`, `OutputUnits`, `UnitPriceUsd`, `TotalCostUsd`, `Currency`, optional `WorkspaceId`/`VideoProjectId`, timestamp.

This is distinct from `ProductionCost` (per-stage aggregate for cost-per-video); `ProviderUsage` is the granular per-call ledger that real adapters write.

## Service

`IProviderUsageLedger.RecordAsync(...)` computes `TotalCostUsd = (inputUnits + outputUnits) * unitPriceUsd` (negatives clamped to zero) and persists immediately, so spend is captured even if the surrounding operation later fails.

## Verification

Backend coverage: usage persisted with computed total and USD currency; negative units/price clamp the total to zero. New migration and `provider_usage` table verified in CI.
