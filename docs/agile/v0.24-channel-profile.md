# v0.24 Channel Profile

## Purpose

Extend the channel with strategic profile fields (backlog US-004, DATA-MODEL Channel: identity, niche, language, operational config).

## Model

`Channel` gains `Niche`, `Audience`, `Language` (default `en`), `Goals` (migration `20260929210712_AddChannelProfile`).

## API

- `GET /api/v1/channels` and `POST /api/v1/channels` now return the profile fields.
- `PATCH /api/v1/channels/{id}` updates the profile (name/niche/audience/language/goals), workspace-scoped. Only provided fields are changed.

## Verification

Backend coverage: profile update persists niche/audience/language/goals; updating a channel from another workspace returns `404`. All existing channel tests still pass.
