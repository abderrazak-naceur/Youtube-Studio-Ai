# v0.31 AI Confidence

## Purpose

Represent confidence/uncertainty in AI outputs where relevant (Definition of Done — AI feature: "confidence/uncertainty is represented").

## Behaviour

`QaResult` gains a `Confidence` value (0..1, default 1.0). `DefaultQaProvider` computes it as `1.0 - 0.15 × findingCount` (floored at 0): a clean pass is fully confident, and each blocking finding lowers confidence. The value is persisted in the `Qa` artifact content alongside `Passed` and `Findings`.

The `Passed` flag (read by the approval gate) is unchanged, so the human quality gate behaves exactly as before; confidence is additive context.

## Verification

Backend coverage: confidence is 1.0 on a clean pass and lower (and within 0..1) when findings exist. CI e2e asserts the QA artifact content carries a `Confidence` value.
