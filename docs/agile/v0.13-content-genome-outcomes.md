# v0.13 Content Genome & Outcome Tracking

## Production-loop position

Learning loop. After a video is approved (Completed), structured attributes are extracted, and performance snapshots can be recorded over time.

This story implements MVP Phase 5 (Content Genome extraction, outcome tracking) and backlog stories US-023 and US-024.

## Content Genome (US-023)

New table `content_genomes` (one row per video project). On approval, the `ApprovalController` extracts:

- `Title` — resolved video title
- `DurationSeconds` — summed scene durations
- `SceneCount` — number of scenes in the scene plan
- `WordCount` — approximate script word count
- `AttributesJson` — up to 10 extracted keyword attributes from the script

Extraction is idempotent: re-approval never creates a second genome.

### Endpoint

`GET /api/v1/video-projects/{id}/content-genome` — returns the extracted attributes, or `404` if no genome has been extracted yet.

## Outcome tracking (US-024)

New table `video_outcomes` (multiple snapshots per project).

### Endpoints

- `POST /api/v1/video-projects/{id}/outcomes` — records a performance snapshot. Requires a source, non-negative metrics, and a `Completed` project.
- `GET /api/v1/video-projects/{id}/outcomes` — lists snapshots, newest first.

Snapshot fields: `Source`, `MeasuredAtUtc`, `Views`, `Likes`, `Comments`, `AverageViewDurationSeconds`, `EstimatedRevenueUsd`.

## Data model

Migration `20260929182818_AddContentGenomeAndOutcomes` creates both tables. `content_genomes` has a unique index on `VideoProjectId`; `video_outcomes` is indexed by `(VideoProjectId, MeasuredAtUtc)`.

## Verification

Backend regression coverage includes genome extraction on approval, genome retrieval states, outcome validation (source, negative metrics, completed-only), outcome persistence and project-scoped listing. The end-to-end CI flow asserts that an approved project exposes a content genome with a positive scene and word count.
