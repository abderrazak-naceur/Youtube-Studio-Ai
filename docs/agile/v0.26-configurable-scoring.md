# v0.26 Configurable Opportunity Scoring

## Purpose

Score opportunities from explicit factors with per-request configurable weights (backlog US-006, CONTENT-ENGINE opportunity score, UX-UI user-adjustable thresholds without editing prompts).

## Scoring model

`OpportunityScoring.Score` is a pure, deterministic function over nine factors (0..100 each): audience demand, search intent, trend momentum, competition, channel fit, monetization potential, production effort, originality potential, evidence quality.

- Competition and production effort are treated as **costs** (inverted), the rest as benefits.
- Weights are relative and normalized, so the result stays on 0..100 for any weight values.
- Returns `opportunityScore`, a `revenueScore` (weighted toward monetization + demand), and a per-factor `contributions` breakdown that sums to the opportunity score.

## Endpoint

`POST /api/v1/opportunities/score` (workspace-scoped): accepts the factors and optional `weights`; returns the computed scores and breakdown. Default weights are used when none are supplied.

## Verification

Backend coverage: perfect benefits / zero costs → 100; higher competition and effort lower the score; weights change the result; contributions sum to the score; out-of-range factors are clamped.
