# v0.37 Frontend Auth

## Purpose

Add the login/register UI so the web app can authenticate against the JWT backend (v0.19). The backend endpoints existed; the frontend now has a way to sign in.

## Component

`AuthPanel`:
- Toggles between **Sign in** and **Create account**.
- Validates email presence and password length (≥ 8) before calling the API.
- Calls `POST /api/v1/auth/login` or `/register`.
- On success, stores the access token in `localStorage` (`ysa.token`) and calls `onAuthenticated(token, email)` so the app can attach `Authorization: Bearer` to subsequent calls.
- Shows a friendly error on failure.

## Verification

Frontend coverage (vitest + testing-library): logs in and reports the token (and stores it); validates password length before calling the API; switches to register mode and posts to `/auth/register`.
