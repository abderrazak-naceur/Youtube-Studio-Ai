# v0.40 Circuit Breaker

## Purpose

Stop hammering a failing provider and fail fast (SYSTEM-ARCHITECTURE §8: timeouts and circuit breakers for external providers).

## Design

`CircuitBreaker` (thread-safe, injectable clock):
- **Closed**: calls pass through; consecutive failures are counted.
- After `failureThreshold` consecutive failures → **Open**: calls are short-circuited with `CircuitOpenException` (the operation is not invoked).
- After `openDuration` → **Half-Open**: one trial call is allowed; success → Closed, failure → Open.
- A success resets the failure count.

## Applied to the HTTP script provider

The provider's resilient HTTP call runs inside the breaker. When the breaker is open, the call is short-circuited and the provider falls back to the placeholder immediately — no wasted requests, production unaffected.

## Verification

Backend coverage: opens after threshold consecutive failures; short-circuits without invoking the operation when open; transitions to half-open after cooldown and closes on success; a success resets the failure count.
