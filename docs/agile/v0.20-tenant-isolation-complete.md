# v0.20 Tenant Isolation — Complete Coverage

## Purpose

Complete the tenant-isolation pass started in v0.19 by protecting the remaining production and research controllers, so every tenant-scoped endpoint enforces workspace membership.

## Controllers now protected (`[Authorize]` + membership)

Production steps (membership via the project's workspace):
- Voice, Visuals, Captions, Music/SFX, Thumbnails, Metadata

Workspace-scoped resources (membership via the `workspaceId` in route/body):
- Opportunities (list/create/update/delete)
- Channels (list/create)
- Research Projects / Sources / Evidence / Claims / Briefs
- Video pipeline (membership via the project's workspace)

For research controllers, the existing `ProjectExistsAsync` helper now also checks membership, so both reads and writes are covered. Non-members get `404` on project-scoped resources or `403` on workspace-scoped actions.

## Result

Combined with v0.19, all tenant-scoped controllers now require authentication and membership. `AuthController` remains anonymous; `/health` remains public.

## Verification

All 148 backend tests pass with authenticated principals injected via the shared `TestAuth`/`StubWorkspaceAccess` helpers.
