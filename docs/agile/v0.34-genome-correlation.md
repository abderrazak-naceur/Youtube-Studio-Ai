# v0.34 Content Genome Correlation

## Purpose

Close the learning loop by correlating Content Genome attributes with measured outcomes (ANALYTICS-INTELLIGENCE Content Genome feedback, AI-AGENT-ARCHITECTURE learning loop). Results are correlational hypotheses, not causal claims.

## Endpoint

`GET /api/v1/workspaces/{workspaceId}/analytics/genome-correlation` (workspace-scoped):

For each completed project that has both a Content Genome and at least one outcome, the latest outcome is used. Views (and estimated revenue) are aggregated per genome attribute, returning:

- `analyzedProjects` — number of projects with both a genome and an outcome
- `attributes[]` — per-attribute `videoCount`, `averageViews`, `averageRevenueUsd`, sorted by average views
- a `disclaimer` stating the result is correlational, not causal (experiments are the way to test hypotheses)

No new tables — it reads `content_genomes`, `video_projects` and `video_outcomes`.

## Verification

Backend coverage: aggregates average views per attribute across projects; ignores projects without an outcome; non-member forbidden.
