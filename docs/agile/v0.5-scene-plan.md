# v0.5 Scene Plan

The MVP flow now includes a focused Script to Scene Plan transition.

API: `POST /api/v1/video-projects/{id}/scene-plan`

The endpoint requires a scripted project, calls the replaceable `IScenePlanProvider`, validates every scene, persists the plan as a `ScenePlan` production artifact, and then moves the project to `Planned`. Invalid provider output leaves the project in `Scripted` and creates no artifact.

Scene validation requires a positive number, positive duration, non-empty narration, and non-empty visual direction.

Tests cover missing projects, missing script, invalid project state, successful provider propagation/persistence/status transition, and invalid provider output.

No vendor SDK or credential is embedded in this implementation.
