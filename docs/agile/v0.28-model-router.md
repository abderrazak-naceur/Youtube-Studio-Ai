# v0.28 Model Router

## Purpose

Route AI work to the best provider/model per task without hard-coding a single provider (MODEL-ROUTER, AI-AGENT-ARCHITECTURE, README AI provider strategy).

## Design

`IModelRouter.Route(request, candidates, weights)` is a pure, deterministic selector:

- **Hard constraints first**: availability, matching task type, `MinQuality`, `MaxUnitCostUsd`. Candidates failing any are excluded.
- **Weighted score** over the eligible set: `Quality`, cost efficiency (relative to the cheapest eligible), `Latency`, `Reliability`. Weights default to quality-leaning but are configurable per call.
- Returns the top candidate with its score and a rationale, or `null` when nothing satisfies the constraints.

Task categories: Script, Image, Video, Tts, Embedding, Research, Qa. Candidates are supplied by the caller (later loaded from configuration/registry), keeping the router provider-agnostic.

## Verification

Backend coverage: picks the highest-scoring candidate; excludes wrong task type, unavailable candidates, over-budget and below-min-quality; cost-weighted config favors the cheaper model.
