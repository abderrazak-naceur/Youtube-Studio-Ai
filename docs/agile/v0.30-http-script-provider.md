# v0.30 Real HTTP Script Provider

## Purpose

First concrete real-provider adapter behind the existing `IScriptProvider` boundary: an OpenAI-compatible LLM over HTTP, configurable and safely optional (PROVIDER-INTEGRATIONS, README Model Router strategy).

## Behaviour

`HttpScriptProvider`:
- When configured (`ScriptProvider:Endpoint` + `ScriptProvider:ApiKey`), calls an OpenAI-compatible chat completions endpoint via `IHttpClientFactory` and returns the generated script.
- When **not** configured, delegates to `PlaceholderScriptProvider` — so the MVP and CI keep working without any provider.
- On any HTTP/parse failure, falls back to the placeholder rather than breaking production.

Credentials come only from server-side config/secrets (`ScriptProviderOptions`); nothing is hard-coded and `appsettings.json` carries no key.

## Verification

Backend coverage: fallback to placeholder when unconfigured; uses the HTTP response body when configured (stubbed handler); falls back on HTTP failure. The CI end-to-end run is unconfigured, so it continues to use the placeholder and stays green.
