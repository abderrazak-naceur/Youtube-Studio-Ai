# v0.33 Revenue Events

## Purpose

Record revenue attributed to content/channels and summarize it (DATA-MODEL Revenue Event, REVENUE-ENGINE attribution and unit economics).

## Model

`RevenueEvent` (table `revenue_events`, migration `20260929214023_AddRevenueEvents`): `Source` (ads/affiliate/sponsorship/product/…), `AmountUsd`, optional `VideoProjectId`/`ChannelId`/`Cta`, `AttributionConfidence` (0..1, exposes uncertainty), `OccurredAtUtc`. Append-only.

## API (workspace-scoped)

- `POST /api/v1/workspaces/{workspaceId}/revenue` — record a revenue event; rejects negative amounts and out-of-range confidence.
- `GET /api/v1/workspaces/{workspaceId}/revenue` — total, breakdown by source (highest first), and the event list.

Non-members get `403`.

## Verification

Backend coverage: record persists; negative amount and invalid confidence rejected; summary totals and groups by source (highest first); non-member forbidden. New migration and `revenue_events` table verified in CI.
