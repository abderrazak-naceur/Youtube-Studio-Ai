# v0.7 Voice

## Scope
Advance the MVP production loop from Visuals to Voice. The API exposes voice generation through the replaceable `IVoiceProvider` boundary and persists the resulting production artifact.

## Endpoint

`POST /api/v1/video-projects/{id}/voice`

Request body:

```json
{
  "voiceId": "optional-provider-voice-id"
}
```

The endpoint requires the project to be in `Producing` state and requires a non-empty persisted `Script` production artifact. The script content and optional voice id are passed to the provider adapter. Provider credentials remain outside the API contract and are never persisted.

A successful provider response must contain a provider asset id and media type. The endpoint persists one `Voice` artifact for the request and leaves the project in `Producing`, ready for subsequent production stages.

## Verification

Backend regression coverage includes missing projects, invalid project state, missing persisted script, provider request propagation, successful artifact persistence, and invalid provider output without partial persistence.
