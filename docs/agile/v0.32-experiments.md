# v0.32 Experiments

## Purpose

Controlled experiments (A/B on title, thumbnail, hook, format, …) per DATA-MODEL Experiment and ANALYTICS-INTELLIGENCE. Each experiment defines a hypothesis, baseline, success metric and decision rule.

## Model

`Experiment` (table `experiments`, migration `20260929213628_AddExperiments`): `Variable`, `Hypothesis`, `SuccessMetric`, `BaselineValue`, `DecisionRule`, `Status` (Draft/Running/Completed/Abandoned), `ResultValue`, `Outcome`, optional `VideoProjectId`.

## API (workspace-scoped)

- `GET /api/v1/workspaces/{workspaceId}/experiments` — list, newest first.
- `POST /api/v1/workspaces/{workspaceId}/experiments` — create (starts in `Draft`); requires variable, hypothesis and success metric.
- `POST /api/v1/workspaces/{workspaceId}/experiments/{id}/result` — record the observed result value, status and outcome.

Non-members get `403`.

Backend coverage: create persists in Draft; validation requires variable/hypothesis/metric; record-result updates status and result; non-member forbidden. New migration and `experiments` table verified in CI.
